افزونهٔ رایگان «خط جدید در تکلیف علوی»

برای صفحهٔ تکلیف دانش‌آموز — بدون دسترسی اضافه به سایت

دانلود افزونه (ZIP) مشاهده در GitHub

این افزونه چه کار می‌کند؟

  • نمایش: متن داخل homework-text با خطوط جدا (مثل سوالات ریاضی و فاصله بین پاراگراف‌ها) دیده می‌شود.
  • نوشتن: با زدن Enter در جعبهٔ تکلیف، خط جدید ایجاد می‌شود (مخصوصاً روی موبایل مفید است).
  • فیلد تک‌خطی: بعضی فیلدها به textarea چندخطی تبدیل می‌شوند.
فقط روی آدرس‌های تکلیف alaviedu.ir فعال است؛ رمز یا اطلاعات شخصی جمع‌آوری نمی‌کند.

نصب روی کامپیوتر (Chrome)

  1. فایل ZIP افزونه را دانلود و از حالت فشرده خارج کنید.
  2. در Chrome بنویسید: chrome://extensions
  3. Developer mode را روشن کنید.
  4. Load unpacked → پوشهٔ افزونه (همان پوشهٔ حاوی manifest.json).
  5. صفحهٔ تکلیف را یک‌بار رفرش کنید.

نصب روی موبایل (رایگان)

Chrome موبایل افزونهٔ سفارشی نصب نمی‌کند. روی اندروید از Kiwi Browser استفاده کنید.

روش Google Drive (پیشنهادی)

  1. روی همین صفحه دانلود افزونه (ZIP) را بزنید.
  2. فایل ZIP را در Google Drive آپلود کنید (یا مستقیم از مرورگر موبایل دانلود شده باشد).
  3. روی گوشی ZIP را دانلود و Extract / استخراج کنید.
  4. Kiwi → منو → Extensions → Developer mode.
  5. +(from .zip/.crx) و انتخاب همان ZIP، یا در صورت وجود، Load unpacked و انتخاب پوشهٔ استخراج‌شده.
  6. سایت علوی را باز و صفحه را رفرش کنید.
