«اطلاح Enter در تکلیف علوی»

برای صفحهٔ تکلیف دانش‌آموز — بدون دسترسی اضافه به سایت

دانلود افزونه (ZIP — دسکتاپ) دانلود افزونه (CRX — موبایل) مشاهده در GitHub

این افزونه چه کار می‌کند؟

  • نمایش: متن داخل homework-text با خطوط جدا (مثل سوالات ریاضی و فاصله بین پاراگراف‌ها) دیده می‌شود.
  • نوشتن: با زدن Enter در جعبهٔ تکلیف، خط جدید ایجاد می‌شود (مخصوصاً روی موبایل مفید است).
  • فیلد تک‌خطی: بعضی فیلدها به textarea چندخطی تبدیل می‌شوند.
  • این افزونه هنگامی کار میکند که معلم حتما Enter را در تکلیف وارد کند.
فقط روی آدرس‌های تکلیف alaviedu.ir فعال است؛ رمز یا اطلاعات شخصی جمع‌آوری نمی‌کند.

نصب روی کامپیوتر (Chrome)

  1. فایل ZIP افزونه را دانلود و از حالت فشرده خارج کنید.
  2. در Chrome بنویسید: chrome://extensions
  3. Developer mode را روشن کنید.
  4. Load unpacked → پوشهٔ افزونه (همان پوشهٔ حاوی manifest.json).
  5. صفحهٔ تکلیف را یک‌بار رفرش کنید.

نصب روی موبایل (اندروید — Microsoft Edge Canary)

Chrome اندروید افزونهٔ سفارشی نصب نمی‌کند. برای موبایل از Microsoft Edge Canary (نسخهٔ آزمایشی Edge) استفاده کنید؛ پشتیبانی افزونه فقط در این نسخه فعال است، نه Edge معمولی.

اول Edge Canary را نصب کنید:

Google Play — Edge Canary کافه‌بازار — Edge Canary

۱) فعال‌کردن Developer options در Edge Canary

  1. Edge Canary را باز کنید → Settings (تنظیمات).
  2. About Microsoft Edge (دربارهٔ Microsoft Edge).
  3. روی شمارهٔ نسخه (مثلاً Edge Canary 154.x) ۵ بار بزنید تا پیام فعال‌شدن Developer options را ببینید.

۲) دانلود و نصب افزونه

  1. همین صفحه → دانلود CRX (یا دکمهٔ دانلود افزونه (CRX — موبایل) بالای صفحه). فایل را در پوشهٔ Downloads ذخیره کنید.
  2. Edge Canary → Settings → Developer options.
  3. Extension install by crx → همان فایل PTagNewLineSupportExtension.crx → Add.
  4. در edge://extensions افزونه را فعال کنید؛ صفحهٔ تکلیف علوی را یک‌بار رفرش کنید.
